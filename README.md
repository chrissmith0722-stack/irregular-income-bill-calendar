# Irregular Income Bill Calendar — Start here

A **monthly bill calendar** for freelancers and variable-income households: map due dates, mark paid, and note which paycheck (or buffer) covers each bill.

> **Scope note:** This is a bill-due calendar only. It is **not** a full cashflow OS, tax-reserve dashboard, or profit-first system.

## What's included

| File | Purpose |
|------|---------|
| `monthly-bill-calendar.md` | Blank month grid + bill list |
| `bill-roster.md` | Master list of recurring bills |
| `HOW-TO.md` | Setup for irregular pay |

Also: `LICENSE` (MIT) · `listing-gumroad.md`

## Quick start

1. Fill `bill-roster.md` once (name, amount estimate, due day).
2. Each month, copy `monthly-bill-calendar.md` and place bills on due dates.
3. When income lands, assign bills to that deposit (notes column).
4. Check off when paid.
